# Sales-Performance-Analysis
A beginner friendly sales analysis project done in Excel 

## Project Background
This project looks at a Nigeria fashion retail Business that sells clothing, footwear, and accessories through its physical store, website, instagram, and Whatsapp, with orders from Lagos, Abuja, Oyo, Rivers and Delta
This Data holds three years of sales data (2024 to 2026). This project brings it together in an interactive Excel dashboard to show what drives revenue and profit, and where the business can grow.
#### Insight and recommendations are provided on the following key areas:
### Sales Trends Analysis
### Product Performance 
### Regional Performance
### Campaign Impact
### Customer Behaviour

## Data Sources
Fashion Retail Sales Dataset
